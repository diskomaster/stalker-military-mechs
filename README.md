# Военные склады: мехи

Тестовый сетевой режим для **S.T.A.L.K.E.R. Тень Чернобыля 1.0006**. Две команды, нейтральные мехи, вертолётные высадки, мутанты, артефакты, радиационный дождь и безопасные базы с покупкой снаряжения.

**Публичный тест: `46.158.177.141:5625`, до 8 игроков, без пароля.** Доступность игровых UDP-портов проверена с другого ПК из другой сети. Подключайтесь напрямую по адресу: появление в общем списке серверов не подтверждено. Сервер работает на тестовом ноутбуке и доступен, пока он включён и сервер запущен.

## Установка

1. Подготовьте отдельную рабочую копию игры версии **1.0006**.
2. Скачайте [M6k-Client-v0.15.zip](https://github.com/diskomaster/stalker-military-mechs/releases/download/v0.15/M6k-Client-v0.15.zip).
3. Распакуйте архив в корень этой копии, рядом с `bin` и архивами `gamedata.db*`.
4. Запустите `Start-M6k-Client.cmd`. Для прямого подключения откройте консоль клавишей `~` и введите:

   ```text
   start client(46.158.177.141/port=5625)
   ```

Также можно положить [Join-Public-Test.cmd](https://github.com/diskomaster/stalker-military-mechs/releases/download/v0.15/Join-Public-Test.cmd) в корень подготовленной игры и запустить его.

Архив содержит мод, карту и отдельный профиль настроек. Оригинальная игра необходима; клиентские EXE/DLL в архив не входят. Всем участникам нужен одинаковый пакет **v0.15**. Сервер не раздаёт эти файлы автоматически.

## Как играть

- На базе наведитесь на ячейку с товаром: **F4, затем 1** — покупка при достаточном количестве денег.
- Деньги дают за урон мехам, убийство противников и доставку артефакта на свою базу.
- У нейтрального меха сначала пробейте отдельную броню двери на спине. После открытия подойдите сзади: **F4, затем 1** — посадка; **F4, затем 0** — выход.
- Подбирайте артефакт и несите его пешком. Во время радиоактивного дождя укрывайтесь под крышей или внутри меха.
- Предупреждения и сведения о событиях появляются в русском игровом чате.

## Серверное исправление 0.15.1

Клиентский пакет остаётся **v0.15**, повторная загрузка не нужна. Купленные и оставленные мехи появляются на земле у базы, их физические координаты сохраняются после сетевых обновлений. Убраны постоянные горизонтальные толчки артефакта, которые прерывали спринт в оригинальном клиенте: теперь передвижение использует обычный спринт с восстановлением выносливости. Броня сохраняется.

После исправлений пройдены 149 проверок на Военных складах и 240 боевых проверок с двумя оригинальными клиентами. Проверены покупки у обеих баз, посадка, выход, повторный захват и переподключение. Короткие проверки ходьбы и спринта выполнены через Bridge; длительный публичный матч ещё нужен.

## Версия 0.15

Исправлены исчезающие стены баз и невидимый потолок изнутри, зеркальные надписи на витринах. Сидорович сохраняет оригинальную анимацию и больше не опрокидывается от попаданий.

Проверено: 138 проверок карты и 240 боевых проверок с двумя оригинальными клиентами, 64 проверки моделей, 98 проверок геометрии и 460 лучей проверки секторов отрисовки. Архив независимо распакован, каждый файл сверён по SHA-256. Это тестовая сборка: длительный матч с полной группой людей ещё нужен для проверки баланса.

Тела мутантов остаются на 60 секунд, обломки мехов — на 90. Они закреплены на поверхности; свободной ragdoll-физики у них нет.
